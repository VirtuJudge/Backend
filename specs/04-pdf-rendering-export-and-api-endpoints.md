# Spec 04: PDF Rendering, Export and API Endpoints

## Problem Statement

Team members need to view the stored canonical report and evaluation, export a private PDF version of the report, and safely download it. The PDF must render without text clipping or omitted sections, matching the canonical report content. All access must be strictly authorized through team membership, and download URLs must be short-lived.

## Solution

1. PDF Rendering Adapter:
   - Port `PDFGeneratorPort` in `app/application/ports/pdf_generator.py`.
   - Implementation in `app/infrastructure/pdf/pdf_generator.py` using pure Python / `pypdf` streams.
   - Comprehensive multi-page document layout: header, executive summary, overall score, dimension score components, whole-team strengths and improvements, individual presenter sections (for each mapped member), Q&A review, timeline, limitations, and generation timestamp.
   - Page budget and line wrapping to guarantee no clipping or truncated text.
2. PDF Storage and Export Service:
   - Save rendered PDF into S3 object storage via `AssetStore` as a verified asset of kind `report_pdf`.
   - Update `ReportExport` record with the resulting `asset_version_id` and status `ready`.
   - Provide short-lived signed download URL via `DownloadIntent`.
3. REST Endpoints in `app/api/routes/reports.py`:
   - `GET /practice-sessions/{session_id}/evaluation` -> `200 Evaluation` or `409 evaluation_not_ready`
   - `GET /practice-sessions/{session_id}/report` -> `200 ReportPayload` or `409 report_not_ready`
   - `POST /practice-sessions/{session_id}/report/pdf` -> `202 ReportExport` or `409 report_not_ready`
   - `GET /report-exports/{export_id}` -> `200 ReportExport` or `403`/`404`
   - `POST /report-exports/{export_id}/download-intents` -> `200 DownloadIntent` or `409 export_not_ready`
4. OpenAPI Contract:
   - Sync OpenAPI contract at `contracts/openapi.json`.

## User Stories

1. As an authorized team member, I want to fetch my practice session's report via `GET /practice-sessions/{session_id}/report`, so that I can see the evaluation summary.
2. As an authorized team member, I want to fetch the evaluation via `GET /practice-sessions/{session_id}/evaluation`, so that I can inspect exact rubric dimensions and scores.
3. As an unauthorized user, I want attempts to view a team's report or evaluation to be rejected with 403 (or 404), so that practice data remains private.
4. As a team member, I want to trigger a PDF export via `POST /practice-sessions/{session_id}/report/pdf`, so that I can download a printable summary.
5. As a team member, I want to fetch a short-lived download URL via `POST /report-exports/{export_id}/download-intents`, so that I can safely download the PDF file.
6. As a team member, I want the generated PDF to contain all report sections without any text clipping or missing presenter sections, so that the document is complete and legible.

## Implementation Decisions

- Pure Python PDF generator using `pypdf.PdfWriter` and clean content streams with Helvetica fonts and text wrapping.
- Verification using `pypdf.PdfReader(strict=True)` on generated bytes to guarantee validity and extractability.
- Fast, secure signed download URL generation using `AssetStore.create_download_intent`.
- Router registered in `app/main.py`.
- OpenAPI regenerated and validated via `python scripts/openapi_contract.py`.

## Testing Decisions

- Unit and integration tests for PDF generation:
  - Valid PDF structure verified with strict `PdfReader`.
  - Verification that text from all mapped presenters and team feedback is extractable and present in the PDF.
  - Multi-page wrapping with multiple sections to verify no crashes or buffer clipping.
- API integration tests:
  - `GET /practice-sessions/{session_id}/report` (200, 404, 409)
  - `GET /practice-sessions/{session_id}/evaluation` (200, 404, 409)
  - `POST /practice-sessions/{session_id}/report/pdf` (202, 409)
  - `GET /report-exports/{export_id}` (200, 403, 404)
  - `POST /report-exports/{export_id}/download-intents` (200, 409)
  - Team authorization tests (member vs non-member).
- Contract verification:
  - `scripts/openapi_contract.py --check` passes with zero drift.

## Out of Scope

- Client-side PDF rendering in the browser.
